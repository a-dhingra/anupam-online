# Project Images To Add

Please add the following images to `/src/assets/Project_images/`:

1. **photography.jpg** - A screenshot of your photography portfolio website (https://lemon-wave-03d25f10f.2.azurestaticapps.net/)
   - Recommended size: 1200x800px or similar aspect ratio
   - Should showcase the main gallery or landing page

2. **codeart.jpg** - A screenshot of your Code Art Studio (https://green-sand-067e6130f.2.azurestaticapps.net/)
   - Recommended size: 1200x800px or similar aspect ratio
   - Should show one of the generated artworks or the interface

## How to capture screenshots:
1. Visit each website
2. Take a full-page or hero section screenshot
3. Resize to approximately 1200x800px
4. Save as .jpg format
5. Place in `/src/assets/Project_images/` folder
